## 💫 Tentang

- 🔧 Membangun firmware dan antarmuka untuk **ESP32** — layar, suara, dan kontrol perangkat
- 🍡 Saat ini mengerjakan **Mochi**, pemutar layar kecil edisi bahasa Indonesia
- 🚗 Juga merakit kontroler **suspensi udara** berbasis ESP32
- 🌱 Belajar merapikan proyek supaya orang lain bisa flash, pakai, dan ikut mengembangkan
- 💬 Terbuka untuk kolaborasi, masukan, dan obrolan soal hardware
